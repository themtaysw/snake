# Snake 🐍

A browser snake game, built one line at a time.

Open `index.html` in a browser to play (once it's finished 😄).

- Arrows / WASD to move, swipe on mobile
- Space to pause, M to mute, G to toggle wrap-around walls, R to restart
- Golden orbs = bonus points, blue orbs = slow motion
- Every 5 apples a new level adds walls
